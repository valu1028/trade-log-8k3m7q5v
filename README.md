# Trade Log｜収支カレンダー

iPhoneのホーム画面から使える、個人用の収支管理PWAです。データはブラウザ内のIndexedDBに保存され、外部サーバーには送信されません。

## 実装済み

- 月間カレンダーと日別収支
- 損失・利益は片方だけでも入力でき、収支を自動計算
- カレンダーの日別収支は「万」に丸めず実額表示
- 月間収支は下部の「収支」タブで表示
- 履歴では損失をマイナス、利益をプラスで明示
- 履歴は前月・今月・次月を選択でき、選択月の記録数・損失・利益・収支を表示
- 画面上部にカレンダー用タグ絞り込みを配置
- カレンダー左下に小さな月間収支、右下に記録追加ボタンを表示
- iPhoneでは画面拡大を固定し、カレンダーと選択日を1画面に収めるコンパクト表示
- 収支記録の追加・編集・削除
- 初期タグ「スキャルピング」「スイング」
- タグの追加・非表示・復元・完全削除
- タグでのカレンダー絞り込み
- 履歴とタグ別分析
- JSONバックアップの書き出し・読み込み
- オフライン起動用PWA構成

## ローカルでの確認

このフォルダでHTTPサーバーを起動し、表示されたURLをブラウザで開きます。

```powershell
python -m http.server 4173
```

## iPhoneへの追加

1. HTTPSで公開したURLをiPhoneのSafariで開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. 「Webアプリとして開く」をオンにして追加します。

記録データの消失対策として、設定画面から定期的にJSONバックアップを書き出してください。
